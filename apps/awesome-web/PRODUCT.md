# Awesome Atlas

แพลตฟอร์ม web สำหรับค้นหาโอเพนซอร์สที่กระจัดกระจายใน GitHub Awesome lists
ผู้ใช้หลักคือนักพัฒนาและผู้สนใจเครื่องมือที่ต้องการเลือกหมวด ค้นหา และกลับมาดู
โปรเจกต์ที่บันทึกไว้ ความสำเร็จคือดูว่าแต่ละลิสต์มีอะไรอยู่ภายใน เทียบว่า
โปรเจกต์ไหนซ้ำกันและไหนเป็นรายการเฉพาะ แล้วเปิดต้นทางหรือเก็บไว้ได้
โดยไม่ต้องสลับไปอ่าน README ของทุกลิสต์เอง

อันดับมีสองฐานข้อมูลที่แสดงแยกกัน: จำนวนลิสต์ Awesome ที่รวบรวม repo
เดียวกัน และลำดับรายวันที่ GitHub Trending archive บันทึกไว้ จำนวนแหล่ง
ที่อ่านแล้ว วันที่ของอันดับ และเครดิตต้นทางต้องมองเห็น เพื่อให้ผู้ใช้ตีความ
ความนิยมตามข้อมูลที่มีได้ การไม่พบ repo ใน Awesome ที่อ่านแล้วไม่ใช่
ข้อสรุปว่าไม่มีในลิสต์ทั้งหมด และจำนวนการถูกอ้างถึงไม่ใช่คะแนนคุณภาพ

ข้อมูลเป็นสาธารณะ ไม่มี login และ browser ไม่อ่านข้อมูลส่วนกลาง
UI ภาษาไทย ชื่อ repository และคำบรรยายต้นทางคงภาษาเดิม
backend แยก มี worker ซิงก์ตามรอบขณะ process ทำงาน ไม่อ้างว่ามี hosted deployment
