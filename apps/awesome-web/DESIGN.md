# Awesome Atlas visual system

หน้านี้เป็น Operate: ค้นหา กรอง และเก็บโปรเจกต์ไว้กลับมาดู
ใช้คลังอ่านสบายที่มี navigation rail คงที่ รายการข้อมูลเป็นศูนย์กลาง
warm white `#faf9f6`, white `#fff`, ink `#302d38`, accent plum `#7050b5`
และเส้นแบ่ง `#e9e6e1` ธีมมืดเปลี่ยนผ่าน CSS tokens โดยคง hierarchy เดิม

DM Sans สำหรับชื่ออังกฤษและ Noto Sans Thai สำหรับภาษาไทย self-host ผ่าน
fontsource Heading 29–40px, ชื่อโปรเจกต์ 13–14px, body description 11–12px
desktop sidebar 240px, content padding 40px, grid 3 คอลัมน์ลดเหลือ 2 และ 1
navigation มือถือเปิด drawer ที่ 760px บทความมีเนื้อหาและ source attribution
ไม่แสดง stars ที่ไม่มีข้อมูลจริง อันดับรายวันใช้ลำดับจาก archive ต้นทาง

Lucide ใช้ stroke เดียวกัน สีพื้น avatar เป็นตัวอักษรแทนการพึ่ง remote images
Focus ring ชัดเจน มี skip link, aria labels, reduced motion และ recovery states
สถานะซิงก์ผิดพลาดยังคงแสดง projection ล่าสุดพร้อมลิงก์ดูต้นทาง

หน้ารายละเอียดใช้หัวข้อและเครดิตลิสต์ก่อนตัวกรองหมวดย่อย หน้าเปรียบเทียบ
ใช้ตัวเลือก A/B ตามด้วยสรุปความซ้ำและปุ่มสี่ชุดรายการ บนมือถือเรียงตัวเลือก
แนวตั้งและปุ่มสรุปสองคอลัมน์ หน้าอันดับใช้แท็บเลือกฐานการจัดอันดับ พร้อม
วันที่ UTC และเครดิตใกล้รายการ เลขอันดับเป็นป้ายเล็กในการ์ดเดิม จึงคงรูปแบบ
การค้นหา การเก็บโปรเจกต์ และการตรวจที่มาไว้ในทุกมุมมอง
